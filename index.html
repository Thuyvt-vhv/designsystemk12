K12Online Design System

Dựng lại đầy đủ thư viện component theo thiết kế Figma K12Online: Button, Input, Table, Modal, Toast, Upload, Date picker… đúng từng chi tiết.

🎨 Brand #005CB6 / #F16022 ♿ WCAG 2.2 AA 🌗 Dark mode 📱 Responsive

Toàn bộ component dưới đây render bằng HTML/CSS thật, dùng đúng design token (màu, spacing, radius). Bật Dark mode ở góc phải để xem theme tối.
